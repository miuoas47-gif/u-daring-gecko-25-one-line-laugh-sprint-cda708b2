A single original one-liner for make.fun's "One-Line Laugh Sprint" bounty: a smart fridge with no jokes left — and no milk, motivation, or 2019 leftovers either. Running `main.py` writes that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates it (one line, 1–280 characters), and verifies it by reading it back. Deterministic, standard library only, no network, no arguments.

## Run it

```sh
python3 main.py
```
